FREE RESOURCE / AI

Use AI better.
Start with better instructions.

A practical beginner-friendly guide to writing useful AI prompts for research, writing, planning, content creation and everyday business tasks.

01 / ROLE

Give context

Tell the AI what role it should perform, who the audience is and what outcome you need.

02 / TASK

Be specific

State the exact task, include useful background and avoid vague instructions.

03 / FORMAT

Define the output

Ask for the structure, tone, length, examples or format you actually need.

QUICK PROMPT FORMULA

Context + task + format = a clearer result.

Try this structure: “Act as [role]. Help me [task]. Use this context: [details]. Return the answer as [format] in a [tone] style.”

Review the response, correct missing details and refine the prompt until the output matches your goal.
