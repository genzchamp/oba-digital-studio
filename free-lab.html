ARTIFICIAL INTELLIGENCE

What is AI, and how can you start using it?

Artificial intelligence describes computer systems designed to perform tasks such as understanding language, recognising patterns, summarising information and generating text or images. AI assistants can help you learn a concept, draft content, analyse information and plan a workflow.

Start with one real task

Choose something specific: understand a topic, outline a report, compare options, draft a customer reply or organize a week's work. Explain the task, provide context and say what a useful result should look like. Review the answer before using it.

Remember: AI is an assistant, not an authority. It can make mistakes or miss context. Check important facts, especially in financial, legal, medical and safety-related decisions.

PROMPT ENGINEERING

How to write better AI prompts

A prompt is the instruction or question you give an AI tool. Communicate the job clearly by including:

  1. Task: state exactly what you want done.
  2. Context: provide background, audience and constraints.
  3. Format: request steps, a table, an outline or a short explanation.
  4. Quality check: ask the tool to flag assumptions or uncertainty.

Example: “Explain how a small shop can use a website to receive enquiries. Assume I am a beginner, use plain language, give me five steps and identify what I should verify.” Ask follow-up questions and improve the answer in stages.

DATA & VISUAL LITERACY

How to read and understand charts

Charts turn data into a visual form so you can notice comparisons, patterns and changes. Check the title, axes, units, scale, source and time period. A line chart often shows change over time; a bar chart compares categories; a scatter plot shows how two numeric variables relate.

Do not confuse correlation with cause. Two values moving together does not prove that one caused the other. Look for context and alternative explanations.

WEB & DIGITAL FOUNDATIONS

How does a website work?

A website is a collection of connected pages and files that a browser requests from a web server and displays on a phone, tablet or computer.

  • HTML: the structure and meaning of the page.
  • CSS: layout, colours, spacing and visual presentation.
  • JavaScript: interactions and dynamic behaviour.
  • Domain: the human-readable address.
  • Hosting: the service storing and serving the files.

Plan the site's purpose, identify its audience, write essential content, build a mobile-friendly layout, publish it and test important links and forms.

PRODUCTIVITY & SYSTEMS

What is automation, and when should you use it?

Automation uses software or connected systems to perform repeatable tasks with less manual effort. Examples include sending order confirmations, organizing form responses or routing enquiries. Map the existing workflow, identify repetitive steps, choose a tool only after understanding the task, then test unusual cases. Keep human review for sensitive decisions.

RESPONSIBLE TECHNOLOGY

How to use digital tools more safely

Use unique passwords, turn on multi-factor authentication where available, keep software updated and check app permissions. Do not paste passwords, private customer records or confidential business data into tools unless you understand how the data is handled. Check links before entering account details, back up important files and review AI-generated content before sharing it.

YOUR NEXT STEPS

A simple path to building digital confidence

Learn one concept, practise it on a small real task, review what happened and improve it. Start with AI basics and prompts, then learn how websites work, understand charts and explore automation for a process you already know. Prefer accessible tools while learning, and pay only when a service solves a real need.

COMMON QUESTIONS

Digital learning FAQs

Can I learn AI without coding?

Yes. Begin with everyday AI assistants for explanations, drafting, planning and research. Coding is only needed for some advanced applications.

Does AI always give correct answers?

No. Verify important facts against reliable sources and use expert advice for high-stakes decisions.

Do I need an expensive computer?

Not necessarily. Many concepts can be learned with a smartphone and internet access. Some development tasks are easier on a computer.

What should I learn first?

Start with a practical goal, learn the basics of the tool that helps with it, practise and build from there.
